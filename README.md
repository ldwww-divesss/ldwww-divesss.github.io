# Dewen Liu's academic homepage

Personal website: https://ldwww-divesss.github.io/

## Editing

- `index.html`: introduction, education, honors, experience, and interests.
- `data.js`: publications, patent, advisors, and links.
- `styles.css`: responsive page styling.
- `main.js`: publication rendering and image enlargement.
- `assets/`: portrait, university emblems, and research figures.

Preview locally with `python3 -m http.server 8765 --bind 127.0.0.1`.
GitHub Pages serves the root of the `main` branch.
